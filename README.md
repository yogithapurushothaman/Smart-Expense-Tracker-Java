# 💰 Smart Expense Tracker

A web-based expense tracking application with analytics.

## Features

- User Login & Signup
- Add Income & Expenses
- Category-based Tracking
- Balance Calculation
- Pie Chart Analytics
- Transaction History
- LocalStorage Persistence

## Technologies Used

- HTML
- CSS
- JavaScript
- Chart.js

## Future Improvements

- Monthly Reports
- Export to PDF
- Backend Integration
- Multi-user support
